## 🛠️ Technologies Used

- Java 17
- Spring Boot 3.x
- Maven (Multi-module)
- Spring Cloud (For service discovery/config)
- MySQL (Database)


## 🚀 Getting Started

### Prerequisites
- JDK 17+
- Maven 3.8+

### Installation
```bash
